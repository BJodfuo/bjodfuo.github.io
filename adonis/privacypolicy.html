Privacy Policy

Adonis Bot • Managed by @bjodfuo

Effective Date: September 2026. We prioritize user privacy and minimal data retention.

1. Information We Collect
Adonis Bot processes strictly necessary data to function within Discord servers:
  • Identifiers: Discord Server IDs, User IDs, and Channel IDs for custom prefixes and permission tracking.
  • Roblox Connections: Linked Roblox User IDs (only if users explicitly link their account for verification/syncing).
  • System Logs: Short-term command logs used solely for rate limiting, operational debugging, and security prevention.
2. How Data is Used & Shared
Stored data is used exclusively to maintain bot settings and execute requested commands. We never sell, share, or disclose collected user or guild data to third parties.
3. Data Retention & Removal
Data is stored as long as the bot remains in your server. Server owners or individual users can request complete removal of their stored settings or linked data at any time through our support channels.
4. Contact & Inquiries
For privacy concerns, data removal requests, or questions regarding our data practices, reach out via our Discord server or email bjodfuo@gmail.com.
